# IXL-bot
The first ever working auto-answer for IXL. It is completley open source, vibecoded in 1 day, and actually works. You need a gemini API key.
 
**How does it works?**
 
Basically all it does is it goes to your api key and asks gemini for the answers. Then the bot will type in the answers for you.
 
**How to install**
1. Install tampermonkey from the chrome web store. Im pretty sure it also works with violetmonkey but u gotta fact check me on it.
2. Then hit "allow userscripts" in the management for chrome (tampermonkey shows you how)
3. Click on tampermonkey then "+ create new script"
4. Then paste the contents of my ixl-bot.user.js into it and hit ctrl+s to save (or cmd+s on mac)
5. go to IXL and the bot will be there! Enjoy!

**Is it safe?**
 
Yeah its safe. its made by AI and open source. Check it yourself.
